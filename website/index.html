Crowmation

Explainer videos written as code, rendered on the GPU. Built for showing how vulnerabilities work, and anything else.

Install

curl -fsSL https://crowmation.com/install.sh | sh

Linux x86_64 with a Vulkan driver. Uses NVENC on NVIDIA GPUs and a fast software encoder everywhere else. Or build from source: cargo install --git https://github.com/InfinitiWarrior/Crowmation crowmation

A scene is a short script

import "std:cybersec"

scene "overflow" {
  let payload = bytes("payload.bin")
  text title "Stack buffer overflow" size 56 at (960, 90)
  hexdump dump data payload cols 16 size 22 below title

  at 0.3s fade_in title
  after fade_in dump stagger 80ms
  after highlight dump.hex[1] color #e5484d  // the return address
}

crowmation preview scene.cwm opens a window that reloads on every save; crowmation render scene.cwm out.mp4 exports. The 36 second video above renders in about 2.5 seconds.

What it does

Text, code and math

Laid out by Typst and drawn as vectors: sharp at any size, with syntax highlighting.

Real data

Load bytes, source files and CSV tables; show them with hex dumps, memory rows and request panels.

2D and 3D together

Load .glb models, orbit the camera, explode and cut them open. 2D and 3D share one space.

Layout and effects

below, right_of, stagger, highlight, shake, groups that move and rotate as one.

Fast export

Hardware encoding on NVIDIA, parallel software encoding elsewhere. Unchanged frames are not redrawn.

Safe to share

Scenes cannot loop forever or read files outside their folder, so opening someone else's is safe.

Editor support

Errors as you type, completion, hover docs and go to definition in Neovim and VS Code.

Helpful errors

Every problem at once, pointing at the line, with "did you mean" suggestions.
